## 代码记录
### optimizer优化器
```
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)   # 定义：告诉它要更新哪些参数、步长多大
loss.backward()        # 1. 自动计算所有参数的梯度
optimizer.step()       # 2. 用梯度更新参数
```
- 作用：根据梯度更新模型参数
- model.parameters() 告诉优化器"你要管哪些参数"（所有权重和偏置）。
- Adam是SGD的改进版，自动给每个参数自适应学习率，收敛更快更稳
### criterion损失函数
```
criterion = nn.MSELoss()      # 定义
loss = criterion(pred, yb)    # 使用：计算预测值和真实值的差距
```
- MSELoss是均方误差
- 只负责计算误差，不负责更新参数

## 循环神经网络
### 循环神经网络RNN
1. 什么是RNN
- 当前状态 = 当前输入 + 过去状态 （ h(t) = f(x(t), h(t-1)) ）
- 公式：
    - h(t) = tanh(W_hh * h(t-1) + W_xh * x(t) + b_h)
    - y(t) = W_hy * h(t) + b_y
    - 其中，tanh是激活函数，W是权重，b是偏置
- 特点：网络的状态会随着时间步不断更新。
- 缺点：
    - 梯度消失和梯度爆炸的问题。普通 RNN 很难记住很久以前的信息。
    - 梯度消失和梯度爆炸的问题可以通过梯度截断（当梯度超过某个阈值时，截断为阈值）来解决。
    - 后续提出的LSTM和GRU等模型，可以解决梯度消失和梯度爆炸的问题。
    - 并行能力弱，时间序列长度过长时，计算量会非常大。

2. RNN的网络架构
- 参数共享：Wxh​,Whh​,Why​,bh​,by​（类似CNN的卷积核，都属于要训练的参数，在网络中是共享的）
- 在时间维度上展开的深层网络
- BPTT（随时间反向传播）：
- 并非每个时间步都有输出（一对一、一对多、多对一、多对多）
- 输入(Embedding)：文字->Token->向量->RNN

#### 问题1：为什么普通神经网络不适合直接处理序列？
普通神经网络主要处理“当前输入是什么”，而 RNN 还会考虑“之前发生了什么”。
#### 问题2：RNN的隐藏状态h(t)到底是什么？
RNN 到当前时间步为止，对过去信息进行编码后形成的“记忆”。注意：隐藏状态不是“原始记忆”，而是神经网络学习出来的“信息表示”。
#### 问题3：RNN的前向传播公式是怎么计算的？
简单来说，就是h(t) = f(x(t), h(t-1))
#### 问题4：为什么RNN能够利用过去的信息？
假设存在h1, h2, h3, h4，则h2包含h1信息，h3包含h2信息，...，由此类推，h4间接包含了h1, h2, h3信息。这也是最终h(t)能利用过去h1~h(t-1)信息的原因。
#### 问题5：RNN为什么会出现梯度消失/梯度爆炸？
- 核心原因：RNN是沿时间展开反向传播的
- 随着时间增加，求导的导函数乘积展开就越多
- 梯度消失：导函数值都很小（小于1），乘积越来越小，最终梯度为0
- 梯度爆炸：导函数值都很大（大于1），乘积越来越大，最终梯度为无穷大
### 长短记忆网络LSTM
- RNN的缺陷
    - 记忆能力弱
    - 梯度爆炸/消失
- LSTM针对上述缺陷做出了改进
- 创新1：(h_t, c_t)的设计
    - 隐藏状态h_t：当前时刻对外输出的短期信息（当前工作状态）
    - 细胞/记忆状态c_t：专门用于长期记忆的信息通道（长期记忆）
    - c_t的更新方式：c(t) = f(t)⊙c(t-1) + i(t)⊙c~(t​)
        - 前半段是上一个时间段的长期记忆在本时间段遗忘门下删除后，保留的之前长期记忆
        - 后半段是根据当前信息计算出来的候选记忆
        - 两者相加后就是当前的长期记忆
- 创新2：门控机制，动态决定什么应该忘记、什么应该记住、什么应该输出
    - Forget Gate 遗忘门：f(t)=σ(W_f[h(t-1), x(t)]+b_f)
        - σ(z)=1/(1+e^(-z))
        - 因此0 < f(t) < 1
        - 假如：f(t)=[0.9, 0.1, 0.8].T，表示第一维保留90%，第二维10%，第三维80%
        - 对旧记忆进行筛选
    - Input Gate  输入门：i(t)=σ(W_i[h(t-1), x(t)]+b_i)
        - 计算候选记忆c~(t)=tanh(W_c[h(t-1), x(t)]+b_c)
        - i决定写多少，c~决定写什么
        - 最终i(t)⊙c~(t​)就是当前准备写入长期记忆的信息
    - Output Gate 输出门：o(t)=σ(W_o[h(t-1), x(t)]+b_o)
        - h(t)=o(t)⊙tanh(c(t))
        - 因此c_t负责保存记忆，h_t负责根据输出门选择“当前应该向外暴露多少记忆”
- LSTM流程：遗忘门f_t->输入门i_t->候选记忆c~_t->更新cell_stage（c_t）->输出门o_t->更新h_t
#### 问题1：为什么LSTM能够缓解梯度消失？
- 仅考虑旧记忆传递，求导梯度c(t)/c(t-1)≈f(t)，当遗忘门f(t)~1时，对于长期传播，最终值不会过快趋近于0
- 但是，这不代表彻底解决梯度消失。因此只能算“缓解”
